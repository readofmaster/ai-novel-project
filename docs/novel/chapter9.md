# 第9章：悟りを開いた園芸家たち

「佐藤さん、見てください。あの一輪のタンポポ」
「ああ、鈴木さん。実に……無防備だ。素晴らしい」

住宅街を飲み込み、もはや宇宙ステーションのような神々しさを放っていた二人の庭は、今や静寂に包まれていた。かつて光り輝き、重力を無視して浮遊し、観光客を熱狂させたあの庭はどこへ行ったのか。現在、境界線上に残されたのは、ただの野原だった。

二人は縁側で冷えた麦茶をすすりながら、荒れ放題に生えた名もなき草花を眺めていた。あれほど高価な肥料を撒き散らし、最新の環境制御装置で気象を操っていた日々が嘘のように、二人はただそこに座っている。

「結局、私たちは何かを支配しようとしていたんですね」
「ああ。だが、庭とは本来、支配から最も遠い場所にあるべきだったのかもしれない」

佐藤は庭いじりのために購入した重機を、すべて近所の廃品回収業者に引き渡した。鈴木もまた、庭に設置していた音響設備を撤去し、代わりに風の音を聞くための安物の椅子を置いた。

「何もしない。これこそが、最強の庭作りだったとは」
「ええ。草は勝手に伸び、虫は勝手に鳴く。私はそれに口出ししない。これほど贅沢なことがあるでしょうか」

二人は微笑み合った。彼らの庭は、誰の管理も受けず、生命の躍動をそのままに解き放たれていた。隣の芝生が青く見えるなんて卑しい悩みは、もう存在しない。だって、彼らにとっての芝生は、いまや「混沌とした聖域」そのものなのだから。

近所の住人が通りかかり、荒れ果てた庭を見て首を傾げる。しかし、佐藤と鈴木は満足げに目を細めた。究極の庭とは、手入れを放棄した瞬間に完成するのだと知ったのだ。
